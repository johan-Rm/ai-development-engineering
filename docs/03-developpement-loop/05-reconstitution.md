# Reconstitution

> Réunir les commits validés pour obtenir le changement complet demandé.

## Entrée

Toutes les tâches attendues sont validées et possèdent leur commit.

## Déroulement

L’IA vérifie la complétude, les dépendances et la branche de réunion autorisée. Elle rassemble les commits, traite les conflits et vérifie les échanges entre les contributions. Une preview peut aider à observer l’ensemble.

## Sortie

Une branche réunissant la demande initiale, prête pour les vérifications de livraison.

## Procédure associée

Aucun skill dédié dans le jeu actuel. La branche de réunion et les opérations Git doivent être explicitement autorisées ; ne pas copier de fichiers non commités entre couches.
