# Consolidation

> La consolidation transforme les constats du projet en corrections globales et en exigences vérifiables pour les développements suivants.

## Renforcer le cadre

Une revue ou un développement peut révéler un écart récurrent, une incohérence ou une pratique à généraliser. La consolidation examine sa présence dans toute la base concernée avant de proposer une réponse.

L’humain arbitre les conventions techniques, les exceptions et les contrôles attendus. L’IA peut ensuite corriger les occurrences retenues et écrire les vérificateurs associés.

## Produire un résultat durable

La consolidation livre du code corrigé, des conventions techniques documentées et des contrôles exécutables sans IA. Elle peut aussi ajuster ou retirer une exigence devenue inadaptée, après décision humaine.

Le développement applique ce cadre ; seule la consolidation autorisée le fait évoluer. Les six étapes sont décrites dans la [boucle de consolidation](../04-consolidation-loop/index.md).
