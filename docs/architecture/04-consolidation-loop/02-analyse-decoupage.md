# Analyse / découpage

> Examiner la base et préparer toutes les cartes avant de modifier une convention technique.

## Entrée

Constat et proposition documentés à l’interview.

## Déroulement

L’IA examine les occurrences, pratiques, exceptions et contrôles existants dans
toute la base concernée. Elle documente la couverture, les limites, les options,
leurs coûts et les contrôles proposés, avec cas conformes et écarts détectables.

### Confirmer la proposition

Les décisions de règle, de portée, d’exceptions et de contrôles nécessaires à
l’implémentation sont confirmées avec l’humain ici, sans étape autonome d’arbitrage.
Une décision déjà explicite reste acquise ; une décision manquante reste ouverte.
L’IA prépare toutes les cartes par couche, avec chemins, branches, dépendances par
commits, critères, tests, documentation et preuves. Le découpage est autonome.

## Sortie

Analyse globale, proposition confirmée et toutes les cartes prêtes. Aucun code,
contrôle ou convention modifié ; aucune validation du résultat futur.

## Procédure associée

`analyser-convention`.
