# Implémentation

> Appliquer la décision humaine dans toute la base concernée et rendre sa vérification exécutable.

## Entrée

Analyse / découpage terminés, décisions nécessaires confirmées et cartes prêtes.

## Déroulement

L’IA réalise les cartes prêtes à l’étape 02, dans leurs couches autorisées, puis documente la convention technique dans les README concernés, corrige les occurrences retenues et implémente les contrôles. Elle teste les vérificateurs sur des cas conformes, des écarts et des exceptions.

Une demande confie toutes ses cartes, sauf restriction explicite. Réaliser les cartes
indépendantes sans validation intermédiaire artificielle ; une vraie dépendance de
code non commitée bloque seulement son consommateur. Aucun transfert de travail
non commité entre couches. Aucun commit à cette étape.

## Sortie

Du code corrigé, une convention technique référencée et des contrôles exécutables sans jugement d’IA.

`implementer-consolidation`.
