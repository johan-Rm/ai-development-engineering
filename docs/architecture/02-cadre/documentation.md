## Relire le code

Les README applicables donnent les responsabilités et les conventions techniques
à confronter au changement. Leurs explications complémentaires aident à comprendre
les raisons d’une règle. Signaler les écarts avec leurs fichiers et les éventuelles
contradictions avec les [instructions du projet](../../../AGENTS.md).

Pour les travaux graphiques, consulter la
[référence du projet](../../../AGENTS.md#références-à-consulter-selon-la-tâche).
