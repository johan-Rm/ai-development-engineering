# Implémentation

> Appliquer la décision humaine dans toute la base concernée et rendre sa vérification exécutable.

## Entrée

Arbitrage approuvé et périmètre de correction défini.

## Déroulement

L’IA prépare les cartes et branches par couche à partir de l’arbitrage, puis documente la convention technique dans les README concernés, corrige les occurrences retenues et implémente les contrôles. Elle teste les vérificateurs sur des cas conformes, des écarts et des exceptions.

## Sortie

Du code corrigé, une convention technique référencée et des contrôles exécutables sans jugement d’IA.
