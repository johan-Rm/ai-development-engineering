# Implémentation

> Appliquer la décision humaine dans toute la base concernée et rendre sa vérification exécutable.

## Entrée

Arbitrage approuvé et cartes affectées aux couches.

## Déroulement

L’IA documente la convention technique dans les README concernés, corrige les occurrences retenues et implémente les contrôles. Elle teste les vérificateurs sur des cas conformes, des écarts et des exceptions.

## Sortie

Du code corrigé, une convention technique référencée et des contrôles exécutables sans jugement d’IA.

## Procédure associée

`demarrer-tache` pour les cartes autorisées. Cette boucle peut modifier `codebase-quality-control/` dans les limites de l’arbitrage.
